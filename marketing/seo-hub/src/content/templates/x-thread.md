# X launch thread template

Tweet-by-tweet. Numbered `.md` files map 1:1 to tweets. Post via the founder
account, archive the live thread URL in frontmatter after posting.

## Structure

```
1/ We just shipped <ASSET_NAME>. <ONE_LINE_PROBLEM_IT_SOLVES>.

2/ Why we built it: <2-sentence origin story with a sharp take on the problem>.

3/ What it does:
- <CAPABILITY_1> (<concrete benefit>)
- <CAPABILITY_2> (<concrete benefit>)
- <CAPABILITY_3> (<concrete benefit>)

4/ What it does NOT do:
- <LIMITATION_1>
- <LIMITATION_2>

5/ Demo: <ASSET_URL>

6/ Who it is for: <SUB_SEGMENT_FROM_SOL3_PLAN>.
Who it is NOT for: <OUT_OF_SCOPE>.

7/ What is broken / missing / next:
- <OPEN_QUESTION_1>
- <OPEN_QUESTION_2>

8/ If you try it, tell me what is missing. Replies > likes. <ASSET_URL>
```

## Mechanics

- File under `/marketing/distribution/x-threads/<slug>.md`
- UTM convention per `/marketing/distribution/analytics.md`
- Tweet-by-tweet post from the founder account
- Archive the live thread URL in frontmatter `live_url`
- Include 2 honest limitations — audiences reward honesty
