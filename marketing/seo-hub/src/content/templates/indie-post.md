# IndieHackers / Show HN template

Two slightly different shapes for the same body. Both lead with the problem,
ship the body in 3 bullets, and end with a question.

## IndieHackers

- Title: `Shipped: <ASSET_NAME> -- <ONE_LINE_VALUE_PROP>`
- Body (<= 200 words): problem (2 sentences), what we built (3 bullets),
  what is missing (2 bullets), link, ask.
- Tags: `indie`, `ship`, `<problem-space-tag>`.

## Show HN

- Title: `Show HN: <ASSET_NAME> -- <ONE_LINE_VALUE_PROP>`
- First comment = the post body; same shape, more technical, lead with the
  limitation. HN hates polished marketing.

## Mechanics

- File under `/marketing/distribution/indie-posts/<slug>.md`
- UTM convention per `/marketing/distribution/analytics.md`
- Cross-post the body to r/SideProject, r/IndieHackers, r/SaaS staggered
  3-7 days apart. Reddit punishes launch-day cross-posts.
- Niche Discords get a 3-sentence variant.
