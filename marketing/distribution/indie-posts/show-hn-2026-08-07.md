# Show HN: StackAuditor — 1-page SaaS stack audit from a screenshot

**Post title:** `Show HN: StackAuditor – 1-page plain-language SaaS spend audit from a screenshot in 60s`

**Post body (first comment = body of post):**

Hi HN — I just shipped StackAuditor.

**The problem.** The average 5-person agency runs 27 SaaS tools. Nobody has
time to audit them. Owners discover they have 3 CRMs and 14 unused seats when
the renewal lands. Existing spend-management tools (Zylo, Productiv, Torii)
want a Salesforce read-only integration and a 30-day implementation — that's
the wrong shape for a solo operator.

**What we built.** A web app. You upload a PNG or PDF of any SaaS dashboard
(Slack admin, Google Workspace, Notion, Stripe — anything). An LLM vision pass
turns it into a structured 1-page audit: wasted spend, redundant seats,
unused features, top security red flags. PDF copy in your inbox in under 60s.
Free first audit, no card.

**Stack.** Next.js 15 (Vercel), Supabase (Postgres + magic-link auth + file
storage), Anthropic Claude Sonnet via the API for the vision + audit pass,
Stripe for paid audits, Resend for email delivery, Plausible for analytics.

**What's missing / not great.**
- OCR on dense custom dashboards is best-effort. Small fonts, non-English UIs
  and bespoke admin pages can be missed — we flag low-confidence reads and
  ask the user to label tools manually.
- This is informational, not advice. We don't replace a human auditor, lawyer,
  or accountant, and the PDF makes that disclaimer explicit.
